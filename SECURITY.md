# Security Policy

## Supported versions

Security fixes are applied to the latest code on `main`. Pre-release and
unreleased App Store builds are not supported through this repository.

## Reporting a vulnerability

Please **do not** open a public issue for a suspected security vulnerability.
Use [GitHub private vulnerability reporting](../../security/advisories/new) if
it is enabled for this repository. If it is unavailable, contact the
maintainer through the repository owner’s GitHub profile with the vulnerability
details and reproduction steps.

We will acknowledge a report within 7 days and provide a status update after
triage. Please allow time for a fix to be prepared before public disclosure.
