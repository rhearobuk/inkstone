## 2. Purpose and audience

Inkstone helps long-form writers organize manuscripts/Story Bible rather than
scattered files. Native drafting/export work without AI. Beyond API access, Editor
uses explicit scope/persona, chunking, response validation, source-matched
evidence links, saved snapshots/history and linked reruns. Critique can be wrong;
the workflow never automatically rewrites the manuscript.

## 4. External services

Writing uses local Core Data/Apple UI, without iCloud or AI sign-in.
CloudKit sync uses the user's private iCloud database when available;
author/agent preferences use iCloud key-value storage.

Editor/Chat support Apple Intelligence, OpenAI, Anthropic, Google, Mistral,
xAI, Cohere and Ollama. Apple Intelligence runs on-device with eligible hardware,
OS 26+ and an enabled, ready model. Ollama is hardcoded to 127.0.0.1:11434:
a same-Mac private service, not configurable LAN/remote hosting.
On iPad/Vision Pro localhost is that device.
Editor uses Junior/Senior models; Chat uses Senior. Models are not bundled.

Cloud AI needs a supported model/network and the user's own key, stored locally
in Keychain. BYOK controls credentials/routing, not provider disclosure:
user-initiated requests send selected text/context directly to the provider,
without a developer proxy. Provider retention, charges and refusals apply.
No automatic cloud fallback occurs; “store: false” does not promise no retention.
